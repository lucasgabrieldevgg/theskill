# scripts/

Shared helper scripts for the `theskill` skill collection.

Currently empty — this directory exists as a placeholder for future shared scripts that multiple sub-skills might use (e.g., a `lint-prose.sh` that wraps `stop-slop` checks, or a `commit-lint.js` that validates Conventional Commits format).

Each sub-skill may also have its own `scripts/` subdirectory for skill-specific helpers.
